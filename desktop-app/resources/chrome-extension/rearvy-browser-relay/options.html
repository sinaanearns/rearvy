Rearvy Browser Relay v0.1.0

Browser control for Rearvy Desktop. Enable Connect only when pairing with the desktop app.

Using Rearvy on the web?

Leave Connect off unless Rearvy Desktop asks for the browser relay. Connect is only for local desktop browser automation.

Not Enabled

Click the toggle or toolbar icon to enable.

Quick Start

Open Rearvy Desktop, create a browser relay pairing code, paste it in Settings, then enable Connect.

How It Works

The extension talks only to the local Rearvy relay at 127.0.0.1. Rearvy sends approved navigation, extraction, click, and typing commands through that local relay.

Status Indicators

Green means connected. Amber means the relay is trying to connect. Red means the desktop relay rejected or could not receive the heartbeat.

Troubleshooting

If pairing fails, create a fresh code in Rearvy Desktop and save it here before the code expires.

If connection still fails, confirm Rearvy Desktop is running and the relay URL matches the desktop app.
