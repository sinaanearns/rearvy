# Firestore JSON Templates

Copy-paste template files for the main Firestore collections used by Rearvy.

## Included files
- integrations.json
- business_metrics.json
- youtube_channels.json
- youtube_videos.json
- youtube_comments.json
- youtube_analytics.json
- shopify_products.json
- shopify_orders.json
- integration_sync_jobs.json
- instagram_accounts.json
- instagram_posts.json
- instagram_comments.json
- instagram_analytics.json
- gmail_threads.json
- gmail_messages.json
- facebook_pages.json
- facebook_posts.json
- facebook_comments.json
- facebook_analytics.json

## Notes
- Replace placeholder IDs, tokens, timestamps, and URLs before pasting into Firebase Console.
- Collections that are not written by current code were intentionally omitted to avoid inaccurate templates.
